# Sabiduría Kairos — Página de ventas

Landing page **responsive** para un producto digital (ebook), construida con **HTML y CSS puro** —sin frameworks ni dependencias— y desplegada en **GitHub Pages**.

🔗 **Demo en vivo:** https://johanrz1206.github.io/sabiduria-kairos-landing/

## Características

- **Mobile-first** y totalmente responsive.
- Estructura de copy orientada a conversión: hero, propuesta de valor, beneficios, prueba social, oferta y garantía.
- Identidad visual propia (paleta azul + dorado, tipografías Montserrat / Lora).
- Carga ligera: HTML/CSS estático, sin JavaScript de terceros.
- Integrable con pasarelas de pago (Hotmart) mediante enlace de checkout.

## Tecnología

- HTML5 + CSS3 (Grid / Flexbox)
- Google Fonts
- GitHub Pages (hosting estático)

## Estructura

```
index.html      → la landing completa
img/            → ilustraciones y mockup del producto
```
